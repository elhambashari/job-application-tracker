
Job Application Tracker

 Projektbeskrivning

Job Application Tracker är en konsolapplikation utvecklad i C# och .NET.

Programmet hjälper användaren att organisera och följa upp sina jobbansökningar.

Projektet är skapat som en skoluppgift för att träna objektorienterad programmering (OOP), LINQ och versionshantering med Git och GitHub.

Funktioner

- Lägga till nya jobbansökningar
- Visa alla jobbansökningar
- Filtrera ansökningar efter status
- Sortera ansökningar efter ansökningsdatum
- Visa statistik över ansökningar
- Uppdatera status för en ansökan
- Ta bort jobbansökningar
- Visa ansökningar som inte fått svar efter mer än 14 dagar
- Visa olika statusar med färger i konsolen
- Kontrollera att användaren anger giltiga uppgifter

Tekniker

- C#
- .NET 10
- Objektorienterad programmering (OOP)
- LINQ
- Git och GitHub
- Visual Studio Code

LINQ

I projektet används bland annat följande LINQ-metoder:

- Where() för att filtrera jobbansökningar
- OrderBy() för att sortera ansökningar efter datum
- Count() för att räkna ansökningar
- Average() för att beräkna genomsnittlig svarstid
- FirstOrDefault() för att hitta en specifik ansökan

 Så kör du programmet

1. Klona projektet från GitHub.
2. Öppna projektmappen i Visual Studio Code.
3. Kontrollera att .NET SDK är installerat.
4. Öppna terminalen.
5. Kör följande kommando:

```powershell
dotnet run
```

6. Följ instruktionerna i konsolmenyn.

Git och GitHub

Projektet har utvecklats med separata branches för olika funktioner:

- feature-job-manager
- feature-menu
- feature-improvements

Ändringarna har hanterats genom Pull Requests och slagits samman med main-branchen.
